## 有意保留的边界

- 没有内置 PIN/手势解锁，所以解锁失败 trace、回放注入统计、录制时间兼容三项未单独引入。
- 当前 API 34+ Root 进程仍保留 root，XMSF 仍保留 iptables 路径。全版本降到 shell 会改变现有后端权限、目录及日志访问，需单独完成 Root/Shizuku × Android 版本设备验证后再切换；本轮没有把其前提不成立的删减直接搬过来。
- 条件返回简化没有单独模仿；Compose 分页、动画、BackHandler 等专用实现没有移植。仅处理本项目可确认的离屏日志开销。
- Root 修复采用最小属性操作。部分 ROM 可能需要额外系统服务刷新；当前不主动重启安全中心，是否能即时恢复注入尚待设备验证，失败时给手动设置指引。
- 历史退出信息的完整度依赖 ROM，API 37 任务排除依赖隐藏接口。Surface/EGL 生命周期和系统重建场景尚未真机验证。
- 调度 claims 的内存缓存能在当前进程内继续去重；若持久化写入失败且之后进程死亡，不能保证跨进程保留这段新 claims。已有 claims 文件损坏时拒绝触发，不盲目继续执行。
